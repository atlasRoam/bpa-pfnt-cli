# Security

This repository distributes legacy Windows executables. Treat binaries and engineering input files as security-sensitive.

- Verify `MANIFEST.json` before first use.
- Run in an isolated engineering workstation or virtual machine.
- Do not process untrusted DAT/control files.
- Do not publish real network data, output reports, or run directories.
- The package performs no automatic update and contains no atlasRoam telemetry endpoint.

Report issues through GitHub private security advisories. Do not attach private grid data, credentials, or proprietary cases.
